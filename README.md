# TypeScript Assignment

## Assignment Overview

In this assignment, I solved 8 problems using TypeScript to improve my understanding of TypeScript fundamentals and practical programming concepts.

### Problems Covered

1. **Optional Parameters** – Created a function to multiply values using a default multiplier.
2. **Union Types & Type Narrowing** – Processed string, number, and boolean values using `typeof`.
3. **Readonly Tuple** – Created a function to format coordinates using a readonly tuple.
4. **Generic Function** – Combined multiple arrays using generics and rest parameters.
5. **Interface & Array Filtering** – Filtered popular published courses based on student numbers.
6. **Generics & Keyof** – Extracted specific property values from an array of objects.
7. **Classes & Inheritance** – Created Employee and Manager classes using protected and private properties.
8. **Promise & Async/Await** – Created an asynchronous age validation function using Promise and setTimeout.
